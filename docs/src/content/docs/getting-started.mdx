Install `@samline/scroll-lock`, then follow the Package / ESM or the HTML / CDN path to the first lock. Both use the same API.

## Requirements

- Any modern browser. Without JavaScript the page keeps scrolling, as it would without the package.
- On the server, every function does nothing and `isScrollLocked()` is `false`.
- No runtime dependencies.

## Package / ESM

```js
import { autoScrollLock } from '@samline/scroll-lock'

autoScrollLock()

document.querySelector('#open').addEventListener('click', () => {
  document.querySelector('#terms').showModal()
})
```

```html
<button type="button" id="open">Read the terms</button>

<dialog id="terms" data-scroll-lock>
  <p>…</p>
  <form method="dialog"><button>Close</button></form>
</dialog>
```

`autoScrollLock()` watches every `[data-scroll-lock]` element, including elements added later, and locks the page while one is open. It returns `{ refresh, destroy }`. To lock from your own code, `const unlock = lockScroll()`. Available as ESM and CommonJS (`require('@samline/scroll-lock')`). There is no stylesheet.

## HTML / CDN

For Shopify, WordPress or plain HTML pages without a build step, load the browser bundle. It watches `[data-scroll-lock]` as soon as the DOM is ready. Pin the version in production.

```html
<script
  src="https://cdn.jsdelivr.net/npm/@samline/scroll-lock@1.0.0/dist/browser/scroll-lock.global.js"
  defer
></script>
```

`ScrollLock.lock()` and `ScrollLock.unlock()` hold one shared lock for inline handlers. To pass options, add `data-manual` to the script tag and start it yourself:

```html
<script
  src="https://cdn.jsdelivr.net/npm/@samline/scroll-lock@1.0.0/dist/browser/scroll-lock.global.js"
  data-manual
  defer
></script>
<script type="module">
  ScrollLock.auto({ positionFixed: 'safari' })
</script>
```
